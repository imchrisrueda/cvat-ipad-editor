# CVAT Mask Editor · iPad Apple Pencil (Offline PWA)

Editor web / PWA instalable en iPad (Safari -> Añadir a pantalla de inicio) para editar máscaras **CVAT for images 1.1** con Apple Pencil en modo **100 % local y sin conexión** (IndexedDB + JSZip).

- **Privacidad:** ninguna foto ni anotación se sube a GitHub Pages; todo permanece en tu iPad (IndexedDB) y en los archivos .zip / .xml que importas y exportas desde *Archivos*.
- Cuando lo abres desde el servidor local del PC (s02_server.py), detecta automáticamente la API local y habilita además **SAM / SAM2**.
